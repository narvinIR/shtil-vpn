Why the app is the size it is

The Windows installer is 18 MB, the phone build is 26 MB, and the universal Android file is 72 MB. Here is where that comes from.

Most of it is the core

The app window itself is small. The bulk is the sing-box core — the program that actually holds the connection. On desktop that is a separate file of roughly 45 MB, shipped inside the package and unpacked on install.

Shipping the core inside is a deliberate choice: the app works right after installation and downloads nothing on first run. "Fetch the core later" is smaller on disk right up until the moment there is nowhere to fetch it from.

Routing lists are inside too

Split routing relies on address lists: what goes direct and what goes through the tunnel. Many clients pull those lists from the network at startup. Ours are compiled into the app — an unreachable list should never stand between you and a working connection.

Why Android has several files

  • A build for your own processor — 26–28 MB. For most phones that is arm64.
  • The universal build — 72 MB: it carries every core variant at once. It helps when the processor is unknown, which is common for TV boxes and set-top devices.
  • App stores usually hide this difference by shipping only the part your device needs. We hand out files directly, so we show them all.
