Speed dropped: what to check before writing to support

"It got slow" comes from different places — a busy link, a saturated network, or a mode sending more traffic through the tunnel than needed. Check in this order.

Separate the tunnel from the network

  1. Measure the speed with the app off. If it is low as well, the network or the plan is the answer and the tunnel is not involved.
  2. Try local sites: they go direct, outside the tunnel. Slow there too — again the network.
  3. If only foreign sites crawl while local ones fly, keep going down this list.

Open diagnostics

The desktop app has a Diagnostics screen with the working log and the list of current connections. That list shows what actually goes through the tunnel — now and then the culprit turns out to be one program pulling an update.

Restart the core

Connections are long-lived, and after a network change — home Wi-Fi to mobile data, say — an old session sometimes hangs around. The restart button on the main screen brings the core back up, which is faster than rebooting the machine.

Check the mode

  • System proxy — only software that reads system settings goes through the tunnel.
  • Tunnel — everything goes through it. It is the heavier mode, and on older hardware the difference shows.
  • If none of that helps, write to support and attach the app log — it shows where things break.
