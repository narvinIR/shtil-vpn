Which macOS build to take: Apple silicon or Intel

We publish two files for macOS. They differ by the processor they are built for, and mixing them up is annoying rather than dangerous.

Finding your processor

  1. Apple menu in the top left corner → "About This Mac".
  2. Read the "Chip" or "Processor" line. "Apple M…" means Apple silicon. "Intel Core…" means Intel.
  3. Download the file marked accordingly.

If you take the wrong one

  • The Intel build on Apple silicon runs through the built-in compatibility layer — slower and noticeably heavier on battery.
  • The Apple silicon build on Intel will not start at all: the system reports the app as unsupported.
  • Either way it is reversible: remove the app, install the right file, and your settings and key are still there.

When there is nothing to choose

Installed through Homebrew, the processor is detected for you and the right build is fetched — updates included.
