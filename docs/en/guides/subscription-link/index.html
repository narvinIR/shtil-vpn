A subscription link instead of a key: why

A key is one line describing one connection. A subscription link is an address where that line lives and keeps itself current. The difference looks small right up until the first time server settings change.

What changes in practice

  • Server settings changed — devices pull the new ones themselves, and nothing has to be re-sent to anybody.
  • One address covers all of your devices: phone, TV, desktop.
  • The expiry date travels with the settings, so the app can honestly show how much time is left.
  • You never type it: the TV reads it off your phone's screen, the desktop takes a short code from the bot.

Where to get it

In the bot, the «My VPN» button. The bare key sits there too, behind a separate button — it is rarely needed, mostly for clients that do not understand subscriptions.

The two-hour trial is taken inside the app with no Telegram at all: it issues a temporary subscription on the same principle.

How many devices

Two at the same time per key. That is not a limit on installs: put the app on five devices if you like — the limit counts simultaneous connections.

A third device does not get a clean refusal; instead connections start breaking for one device, then another. If your link feels unstable, first check whether an old phone is still connected.
