macOS refuses to open an app from outside the App Store

macOS will not allow the first launch of a program downloaded outside the App Store. This is expected behaviour, and there is a supported button for it — nothing needs to be broken.

How to open it

  1. Try opening the app with a normal double click. The system refuses — as designed.
  2. Open System Settings → Privacy & Security.
  3. Scroll to the bottom: a line about the blocked app appears, with an «Open Anyway» button.
  4. Click it and enter the administrator password. From then on the app opens with a double click and the question does not return.

Two different messages — do not confuse them

  • «Developer cannot be verified» — the ordinary case: the app is signed but not notarised by Apple. The button above handles it.
  • «The application is damaged and should be moved to the Bin» — a different thing: there is no signature at all and the browser attached a quarantine flag. In that case the system shows no override button.

What to do about the second one

Download a current build from our address: since August 2026 macOS builds are signed with our own key and this message no longer appears.

There are two Mac builds — Apple silicon and Intel. The browser does not reveal which one you need, which is why the page shows two buttons; if the app will not start, check that you took the right build first.

Why the app is not in the App Store

Only a company can publish there, not a private person. So the file is served directly, and the app finds its own updates, installing only what is signed with our key.
