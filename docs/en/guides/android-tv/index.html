Installing a VPN on Android TV when the box has no browser

Android TV sets and boxes usually have no browser, and the app store does not show what is not in it. The file goes in through a downloader app — the standard route on that system. Typing the address with the remote is no longer needed: there is a numeric code, and with an Android phone nearby nothing is typed on the remote at all.

What you need

  • An Android TV set or box — version 6.0 or newer.
  • The remote. A mouse and keyboard are not required, but they are faster.
  • Any downloader app from your TV store. Downloader by AFTVnews is the most common one and is available almost everywhere. It is easier to find by voice — the remote has a microphone button.
  • A phone nearby — handy for opening the bot and showing the TV a code.

Steps

  1. Open the store on your TV and install Downloader if it is not there yet. Saying the name out loud beats typing it with the remote.
  2. Launch it and click the address bar at the top: it takes both a code and an address. Type 7962408 and press «Go». If digits are easier, the «#» button to the right of the bar opens a number pad. The pad exists precisely for TVs: a code is four times quicker than an address, because it has no dots, no slash and no letters.
  3. The file downloads on its own. The system asks once for permission to install apps from this source — grant it to the downloader app.
  4. Then Google shows a red verification screen. It is the standard warning for any file from outside the store; the button you need is «Install anyway», at the bottom, reachable with the remote.
  5. Open Shtil and press «Try now» — two hours run straight away, with no Telegram and no email.
  6. For a permanent key take the linking code from the bot: the TV shows a field for a short code and the phone shows the code as a picture. The key arrives by itself.

With an Android phone nearby: nothing typed on the remote

The phone and the TV must sit on the same home network. A guest network with device isolation breaks this route — fall back to the code then.

Why the TV gets the 32-bit build

TV boxes are overwhelmingly 32-bit, even recent models. The remote-friendly address always serves the 32-bit build: it runs everywhere, while the 64-bit one simply refuses to install on half of them.

Installing on a phone instead? Use the main button on the home page — it picks the right build for your device automatically.

If the downloader rejects the address

If the code does not go through, type the full address: sub.ndvsdom54.ru/tv.apk — it leads to the same file and depends on nothing.

Downloader dislikes addresses that start with «https://» — type the string exactly as shown, starting at «sub».

Some firmwares block installs from a downloader app until «unknown source» is allowed for that very app in the security settings. The permission is granted once and stays.
