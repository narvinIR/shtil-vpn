Installing a VPN on Android TV when the box has no browser

Android TV boxes rarely ship a browser, and the store only lists what the store has. The normal way in is a downloader app — it takes a couple of minutes and uses nothing but built-in system behaviour.

What you need

  • An Android TV box or TV set, version 6.0 or newer.
  • The remote. A mouse and keyboard make it faster but are not required.
  • Any downloader app from your TV store. Downloader by AFTVnews is the most common one and is available almost everywhere.
  • Your phone nearby — handy for opening the bot and showing the TV a pairing code.

Steps

  1. Open the store on your TV and install Downloader if it is not there yet.
  2. Launch it and type this address with the remote: sub.ndvsdom54.ru/tv.apk — no «https://», no «www». The address is deliberately short, because typing long strings with a remote is painful.
  3. The file downloads on its own. The system will ask once whether this source may install apps — allow it for the downloader.
  4. Next comes Google's red verification screen. It appears for any file installed outside the store; the button you need is «Install anyway», at the bottom, reachable with the remote.
  5. Open Shtil and press «Try now» — two hours start immediately, with no Telegram and no email.
  6. For a permanent key, take a pairing code from the bot: the TV shows a field for a short code, the phone shows the code as an image. The key arrives by itself.

Why the TV gets the 32-bit build

TV boxes are overwhelmingly 32-bit, even recent models. The remote-friendly address always serves the 32-bit build: it runs everywhere, while the 64-bit one simply refuses to install on half of them.

Installing on a phone instead? Use the main button on the home page — it picks the right build for your device automatically.

If the downloader rejects the address

Downloader dislikes addresses that start with «https://» — type the string exactly as shown, starting at «sub».

Some firmware blocks installs until «unknown sources» is enabled for that specific downloader in the security settings. You grant it once and it stays.

The app is installed — what now

One button connects. While the tunnel is up, local sites stay on the direct route — which matters on a TV, because built-in services and firmware updates go straight out and stay fast.

Updates are found by the app itself: when a new version appears, it offers to install it on the same screen.
