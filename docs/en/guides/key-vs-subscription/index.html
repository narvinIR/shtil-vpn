Key or subscription link: what to move to a new device

The bot hands you two things: a subscription link and a key as a plain string. They look different because they do different jobs — and on a new device you notice immediately.

The short version

  • Subscription link — an address the app fetches a ready configuration from: server, encryption and routing rules in one go.
  • Key — a single string holding the server address and connection parameters. It carries no routing rules.

Why a new device is better set up with the subscription

A subscription refreshes: the app re-reads it and picks up current settings. If the server moves or the rules change, you re-enter nothing.

A key is a snapshot taken at the moment it was issued. It keeps working while the address holds, but routing has to be set up in the client by hand. That is the usual reason people report local sites and banks going through the tunnel.

Moving it over

  1. Open the bot and take the subscription link — it is the same one for all of your devices.
  2. In our app you do not have to type it: the bot shows a pairing code and a QR, and the app reads it and configures itself.
  3. The plain key sits next to it under its own button — you need it for third-party clients that do not understand subscriptions.

How many devices at once

Two simultaneous connections per account. That is not a limit on how many devices you may install the app on, but on how many are connected at the same moment: a phone and a desktop work together, a third connection starts pushing the others off.
