«Windows protected your PC»: what it is and what to press

The blue window looks alarming while saying something quite modest: «I am seeing this program for the first time». Here is where it comes from and what to press.

Getting through

  1. In the blue window click «More info» — the link is inconspicuous on purpose.
  2. A «Run anyway» button appears. Click it.
  3. The installer then behaves normally, and the prompt will not come back on later launches.

Why it appears

Windows does not judge the contents of a program; it judges its reputation — how many people have already run this exact file, and whether it carries a publisher certificate. A new program has no reputation by definition.

We did not buy a publisher certificate. Since 2024 instant trust is not for sale anyway: the rules tightened, and reputation is still earned through install counts. We would rather explain the prompt in plain words than charge the subscription for it.

How to check the file if you are uneasy

  • Download only from our address or the releases page — file names are permanent and do not change between versions.
  • Any file can be checked with free online scanners that run dozens of antivirus engines at once.
  • The desktop app's sources are open, and the build is produced from them in public.

Updates

Once installed, the app checks for new versions itself and installs only what is signed with our own key. So you see the prompt exactly once — at first install.
