iPhone: adding the subscription to a third-party client

There is no iPhone build from us: publishing to the App Store requires a company, not a person. The subscription link, however, is a standard one and opens in any client running the sing-box or Xray core.

What you paste

The bot has a «My VPN» button that hands you a subscription link — a single line starting with https://sub.ndvsdom54.ru/sub/… That is what goes into the client.

A subscription link beats a bare key: when server settings change, the app pulls the new ones itself and nothing has to be re-shared.

Steps in v2RayTun

  1. Install v2RayTun from the App Store.
  2. Copy the subscription link from the bot.
  3. In the app tap «+» → «Add from clipboard». The client parses the link and loads the profile.
  4. Select the profile and tap connect. iOS asks once for permission to add a VPN configuration — a system prompt, and the tunnel will not come up without it.
  5. Verify it works: open any foreign site, then any local one — the second should load exactly as fast as it did without the VPN.

What not to do

  • Do not push your own routing rules into it: v2RayTun has built-in ones that work, and it silently ignores custom deep links and headers.
  • Do not change the TLS fingerprint. For Reality on iPhone it must be chrome — with safari the connection drops, which has been confirmed more than once.
  • Do not keep two VPN profiles active at once: iOS gives the tunnel to one of them, and the other will show «connected» while doing nothing.

If it keeps dropping

Check the boring things first: subscription expiry in the bot, low-power mode, and iCloud Private Relay — the last one conflicts with the tunnel.

Re-creating the profile from the link helps more often than it should: clients cache old settings longer than you expect.

One key serves two devices at the same time. If the iPhone is the third one, connections will keep breaking — disconnect a device you no longer use.
