What sing-box is and why the app is built on it

sing-box is an open-source core that does the actual work: it holds the tunnel, reads the routing rules and decides where each request goes. The app around it is the screens, the buttons and the link to the bot.

What it can do

  • Speak several protocols from one core — VLESS, Trojan, Shadowsocks and others, without a separate program for each.
  • Split routes by rule: domain, address, country, or a specific app on the device.
  • Raise a system-wide tunnel that carries every program's traffic, not just the browser's.
  • Resolve names itself — which matters, because a plain name lookup leaks half of your privacy.

Why the core ships inside the app

Many clients download the core and the routing lists on first launch. That works beautifully until the day the address they download from stops answering: the app is then empty and will not connect.

Ours are compiled in. The internet is needed for the connection itself and nothing else — install and it works, even when third-party addresses are unreachable.

What configuration looks like

A sing-box configuration is a plain JSON file: inbounds, outbounds, routing rules. The subscription serves a ready-made one, and the app only adjusts local ports in it.

That is also what makes the subscription portable: the same address opens in any client on the same core — desktop, phone or TV box.

Licence and source
