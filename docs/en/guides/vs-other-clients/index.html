How this app differs from Hiddify and Throne

Hiddify and Throne are universal clients: you paste any service's subscription into them. Our app is built around one service. Every difference follows from that.

Where the configuration comes from

  • In a universal client you paste a link or a key, and set up routing yourself if you want it.
  • Here the configuration arrives ready-made: server, encryption and split-routing rules are already assembled, and a pairing code from the bot is all the input there is.

Before paying, and without an account

Our app has guest access: two hours of use with no Telegram and no sign-up, so you can see how it behaves on your own network. A universal client with no third-party subscription does nothing — it has nothing to connect to.

Updates and languages

  • The app checks for new versions itself and installs only builds signed with our key.
  • The interface is translated into five languages — the same set the bot speaks.
  • Routing lists are compiled into the app rather than fetched at startup.

What is shared

All three run the same core underneath: sing-box. That is why our subscription link works in the other clients too — if Hiddify or Throne is what you are used to, installing our app is optional.
