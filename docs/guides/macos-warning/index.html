macOS не открывает приложение не из App Store

Первый запуск программы, скачанной мимо App Store, macOS не разрешит. Это ожидаемое поведение системы, и обходится оно штатной кнопкой — ломать защиту не нужно.

Как открыть

  1. Попробуйте открыть приложение обычным двойным щелчком. Система откажет — так и должно быть.
  2. Откройте «Системные настройки» → «Конфиденциальность и безопасность».
  3. Прокрутите вниз: там появится строка о заблокированном приложении и кнопка «Открыть всё равно».
  4. Нажмите её и введите пароль администратора. Дальше приложение открывается обычным щелчком, вопрос больше не повторится.

Два разных сообщения — не путайте

  • «Не удаётся проверить разработчика» — обычный случай: программа подписана, но не заверена Apple. Проходится кнопкой выше.
  • «Приложение повреждено и должно быть перемещено в Корзину» — другое: подписи нет вовсе, а браузер повесил на файл метку карантина. Кнопки обхода в этом случае система не показывает.

Что делать со вторым случаем

Скачайте свежую версию с нашего адреса: с августа 2026 сборки для macOS подписываются нашим собственным ключом, и это сообщение больше не появляется.

У Мака две сборки — для процессоров Apple и для Intel. Браузер не сообщает, какой у вас, поэтому кнопки на странице разные; если приложение не запускается, первым делом проверьте, ту ли сборку скачали.

Почему приложения нет в App Store

Публиковать в магазине может только компания, а не частный человек. Поэтому файл раздаётся напрямую, а обновления приложение находит само и ставит только подписанное нашим ключом.
