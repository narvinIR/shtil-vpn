Ссылка-подписка вместо ключа: зачем так

Ключ — это одна строка с настройками одного соединения. Ссылка-подписка — адрес, по которому эта строка лежит и обновляется. Разница кажется мелкой ровно до первой смены настроек на сервере.

Что меняется на практике

  • Настройки на сервере поменялись — устройства подтягивают новые сами, рассылать никому ничего не нужно.
  • Один адрес работает на всех ваших устройствах: телефон, телевизор, компьютер.
  • Вместе с настройками приезжает срок подписки, поэтому приложение может честно показать, сколько осталось.
  • Ссылку не нужно набирать руками: телевизор считывает её с экрана телефона, компьютер — по короткому коду из бота.

Где взять

В боте, кнопка «Мой VPN». Там же под отдельной кнопкой лежит голый ключ — он нужен редко, например для клиента, который подписки не понимает.

Пробный доступ на два часа берётся прямо в приложении, без Telegram: он выдаёт временную подписку по тому же принципу.

Сколько устройств

Два одновременно на один ключ. Это не число установок: приложение можно поставить хоть на пять устройств, ограничение считает одновременные соединения.

Третье устройство не «не подключится» — вместо этого начнёт рвать соединение то одному, то другому. Если связь нестабильна, первым делом проверьте, не забыт ли включённым старый телефон.
