iPhone: как добавить подписку в сторонний клиент

Своей сборки под iPhone у нас нет: чтобы выложить приложение в App Store, нужна компания, а не человек. Зато ссылка-подписка — стандартная, она открывается в любом клиенте на ядре sing-box или Xray.

Что вставлять

В боте есть кнопка «Мой VPN» — она выдаёт ссылку-подписку. Это одна строка вида https://sub.ndvsdom54.ru/sub/…; её и нужно добавить в клиент.

Ссылка-подписка удобнее голого ключа: когда настройки на сервере меняются, приложение подтягивает новые само, и переносить ничего не нужно.

Шаги в v2RayTun

  1. Поставьте v2RayTun из App Store.
  2. Скопируйте ссылку-подписку из бота.
  3. В приложении нажмите «+» → «Добавить из буфера обмена». Клиент сам разберёт ссылку и загрузит профиль.
  4. Выберите профиль и нажмите «Подключить». Первый раз iOS попросит разрешение на добавление конфигурации VPN — это системный запрос, без него туннель не поднимется.
  5. Проверьте, что соединение живо: откройте любой зарубежный сайт и заодно любой российский — второй должен открываться так же быстро, как без VPN.

Чего делать не надо

  • Не подставляйте свой набор правил маршрутизации: у v2RayTun есть встроенные, и они работают, а самодельные ссылки и заголовки клиент молча игнорирует.
  • Не меняйте отпечаток TLS. Для Reality на iPhone он должен быть chrome — с safari соединение обрывается, это проверялось не один раз.
  • Не держите включёнными два VPN-профиля сразу: iOS отдаёт туннель одному, а второй будет показывать «подключено» и не работать.

Если отваливается

Сначала проверьте очевидное: срок подписки в боте, режим энергосбережения и «Частный узел iCloud» — последний конфликтует с туннелем.

Помогает пересоздать профиль из ссылки заново: клиент кэширует старые настройки дольше, чем кажется.

Один ключ работает на двух устройствах одновременно. Если iPhone третий по счёту, соединение будет рваться — отключите лишнее устройство.
