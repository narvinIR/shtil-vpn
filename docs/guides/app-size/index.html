Почему приложение весит столько, сколько весит

Установщик для Windows — 18 МБ, приложение для телефона — 26 МБ, а универсальная сборка сразу 72 МБ. Разберём, из чего это набирается.

Основной вес — ядро

Само окно приложения весит немного. Основную часть занимает ядро sing-box — программа, которая и держит соединение. На компьютере это отдельный файл примерно на 45 МБ, он лежит внутри пакета и разворачивается при установке.

Ядро внутри — сознательный выбор: приложение работает сразу после установки и ничего не докачивает при первом запуске. Вариант «скачаем ядро потом» короче на диске ровно до того момента, когда докачивать его будет неоткуда.

Списки маршрутов тоже внутри

Разделение трафика опирается на списки адресов: что идёт напрямую, а что через туннель. Многие клиенты подтягивают такие списки из сети при старте. У нас они собраны внутрь приложения — недоступный адрес списка не должен мешать соединению.

Почему у Android несколько файлов

  • Сборка под свой процессор — 26–28 МБ. Для большинства телефонов это arm64.
  • Универсальная — 72 МБ: в ней лежат сразу все варианты ядра. Она нужна, когда неизвестно, какой процессор в устройстве, и удобна для телевизоров и приставок.
  • Из магазина приложений такой разницы обычно не видно: магазин отдаёт устройству только нужную часть, а мы раздаём файлы напрямую и потому показываем их все.
